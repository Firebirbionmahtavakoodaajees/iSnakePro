## Making

The game is made with godot. Development happened with .Net activated Godot, but the project will be 100% realized in GDScript.
- Lightweight
- Optimized, not going to contain more than 1 set of nesting.
- Process will be fully documented down below:

### Documentation

**The porject is still in alpha phase! Please report all bugs found :)**

**Installation:**
- The game is portable. Just move it to a folder you'd like to keep it in. Launch when wanting to play the best snake game made by me :D

**Usage**
- W to move up
- A to move left
- S to move down
- D to move right
